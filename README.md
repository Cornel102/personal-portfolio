# Single-Page Personal Portfolio Website

[![Live Demo](https://img.shields.io/badge/Live_Demo-GitHub_Pages-brightgreen?style=for-the-badge&logo=githubpages)](https://cornel102.github.io/personal-portfolio/)
[![Developer](https://img.shields.io/badge/Developer-Cornelius_Nkwocha-blue?style=for-the-badge&logo=github)](https://github.com/cornel102)

A clean, responsive, single-page personal portfolio website built entirely from scratch using vanilla HTML5, CSS3, and JavaScript. Designed as part of the preliminary developer assessment for Bincom Dev Center to showcase professional experience, core skills, technical projects, and personal highlights.

---

## ✨ Features & Sections

- **Hero Header:** Welcoming banner with a brief summary and smooth action button.
- **About / CV Summary:** Highlighting my B.Tech in Information Technology from FUTO, background, and career focus.
- **Technical Skills:** Structured breakdown of Frontend, Backend, Databases, and DevOps tools.
- **Key Projects:** Showcasing full-stack applications including the GPA Calculator RESTful API and Task Tracker.
- **Photo Gallery:** Responsive image grid featuring personal, campus, and community moments (5+ images).
- **Interactive Contact Form:** Client-side form feedback implemented with vanilla JavaScript event handling.
- **Responsive Layout:** Optimized across desktop, tablet, and mobile viewports using CSS Grid and Flexbox.

---

## 🛠️ Tech Stack & Constraints

- **Structure:** HTML5 (Semantic elements)
- **Styling:** CSS3 (Custom Flexbox, Grid, CSS Variables, Smooth Scrolling)
- **Interactivity:** JavaScript (ES6+ Vanilla DOM Manipulation)
- **Deployment:** GitHub Pages
- **Constraints Applied:** Built 100% from scratch without pre-built templates, Bootstrap, or heavy CSS frameworks.
